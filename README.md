# Control de Consignaciones

PWA local para registrar clientes, productos, entregas en consignación, cantidades vendidas/devueltas, pagos y comprobantes por WhatsApp.

La versión 2 agrega imágenes por producto, costos, marcas (Tomá Mate y Dulce Toque), comisión propia de cada comercio e informe de ganancias con separación 50/50 entre compras y ahorro.

## Uso local

Abrir la carpeta con un servidor local (por ejemplo Live Server). Los datos se guardan en `localStorage` del navegador. Desde Respaldo se pueden exportar e importar en JSON.

## Publicación

Es una app estática y puede publicarse gratuitamente en GitHub Pages.
